OMNITHEL MAGIC ITEMS - setup
1. Make a GitHub repo (e.g. magic-items), upload ALL files in this folder to the repo root.
2. Settings > Pages > Deploy from branch > main / (root).
3. Open the Pages URL on the tablet in Chrome, wait a moment, then menu > Install app / Add to Home screen. It works offline after the first load.
Your data (inventory, fail counts, edits) is stored in that browser - use Backup > Export regularly.
